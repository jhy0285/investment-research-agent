# 합성 cross-asset 연구 사례

[case.json](case.json)은 오프라인 연구 흐름을 검증하기 위한 입력이다. 기관·기업·전문가·커뮤니티·관측값·검토 기록은 모두 합성이며 실제 시장 자료나 실제 사용자 원장이 아니다. 정보 기준일은 `2025-01-31`로 고정한다. 실행한 날의 시장에 대한 답으로 읽으면 안 된다.

연구 질문은 “한국의 자산축적기 투자자가 추가 자금을 배분할 때 현금성 자산·국채·주식 노출 중 무엇을 더 조사할 이유가 있는가?”다. 특정 상품, 매매 명령, 자산 순위, 최적 비중을 만들기 위한 사례가 아니다.

## 입력에서 확인할 경계

| 구분 | 사례에 포함한 내용 |
| --- | --- |
| 사용자 | 대한민국 세법상 거주자, 출생연도, KRW, 자산 축적기, 안정적인 근로소득, 장기 투자 가능이라는 가상 자기보고 |
| 미확인 사용자 정보 | 총자산·비상자금·부채·주택 구입 필요자금·보유 구성·월 투자 가능액·위험 감당 능력을 `unknown`과 `null`로 유지 |
| 출처 | 공식 원자료·기관·데이터 제공자·전문 연구·뉴스·전문가·커뮤니티 유형을 각각 표현 |
| 원출처 의존 | `S_NEWS`는 `S_PRIMARY`를 재인용한다. `E_NEWS_INFLATION`과 `E_INFLATION`은 독립 확인이 아니다. |
| 상충 자료 | 주식 이익·유동성 개선과 가격 부담·참여 범위 약화, 국채 수익률·완화 기대와 물가·금리 손실 위험 |
| 범위 | 현금성·국채·주식의 합성 노출만 조사하며 한국 부동산·회사채·원자재·암호자산·실제 상품은 이유와 함께 보류 |
| 비교 제한 | 기간·통화·수익 정의·비용·세금·환헤지·유동성·불확실성을 공개하고 서로 다른 개념을 미래 수익률 순위로 바꾸지 않음 |

출처의 `synthetic://` 식별자는 인터넷 주소가 아니다. 근거의 `locator`는 이 JSON에 담긴 합성 구절을 식별한다. 최초 버전에는 별도의 실제 원문 파일이 없으며, 원문과 상태를 자동으로 사실 검증했다고 주장하지 않는다. `synthetic-fixture-review`는 합성 사례를 구성하며 명시한 검토 역할이고 실제 금융 연구를 수행한 사람이나 기관의 서명이 아니다.

## 사람이 직접 확인할 기대 결과

`E_CASH_RATE`의 합성 명목 연 이자율은 `2.5%`, `E_INFLATION`의 합성 후행 연간 물가상승률은 `3.0%`다. `M_CASH_RATE_GAP`은 순서가 고정된 두 입력을 십진 연산으로 빼므로 결과는 **`-0.5 percentage_points`**다. 이는 명목 이자율과 후행 물가율의 기술적인 차이다. 미래 실질수익, 동일 기간의 실현 구매력 변화, 세후 수익을 뜻하지 않는다. 두 입력·방법 ID·한계를 보고서에서 추적할 수 있어야 한다.

| 주장 ID | 기대 상태 | 확인할 의미 |
| --- | --- | --- |
| `C_EARNINGS` | `supported_within_scope` | 합성 기업군의 보고된 이익 증가 구절만 확인됨. 미래 주식 수익은 확인되지 않음 |
| `C_YIELD_ORDER` | `contradicted_within_scope` | 의도적으로 잘못된 “장기 국채 만기수익률이 정책금리보다 낮다”는 주장을 합성 관측값 `4.5%`와 `3.5%`로 반박 |
| `C_MARKET_EASING` | `partially_supported` | 정책 완화 기대의 단서는 있으나 실제 큰 인하의 시점·실현은 미확인 |
| `C_EQUITY_BALANCE` | `disputed` | 주식의 지지·반대 자료를 함께 유지하며 상충을 점수로 해소하지 않음 |
| `C_BOND_NARRATIVE` | `not_verifiable` | 기준 시점에서 큰 금리 인하와 거의 확실한 투자성과를 확인할 수 없음 |
| `C_LIQUIDITY_CAUSALITY` | `unverified` | 유동성 개선이 주가 상승의 원인이라는 주장은 인과 검토가 없고 해석도 `pending`이므로 확정 인사이트로 사용하지 않음 |

`E_COMMUNITY_BOND`의 확인 상태는 합성 토론에 해당 **발언이 존재한다**는 관측에만 적용한다. 발언 내용의 진실성을 다루는 `C_BOND_NARRATIVE`와 분리한다. 커뮤니티의 지지·반대 참조는 검증할 논점이며 현재 금리·완화 기대를 붙였다는 이유로 미래 수익이 확정되지는 않는다.

각 대안의 기회비용은 나머지 대안을 선택하지 않을 때 포기하는 가능성과 감수하지 않을 위험을 함께 설명한다. 모든 설명은 근거 ID와 합성 검토 기록을 갖는다. 미래 수익 차이는 계산하지 않는다.

전체 실행이 완료되어도 시장 결론은 강한 결론 유보가 정상이다. 주식과 국채의 상충을 숨기지 않고 개인 배분 적절성은 미확인 사용자 정보 때문에 제한해야 한다. 현금의 상대 우위, 과도한 현금 비중, 전체 포트폴리오의 안전성도 확정하지 않는다.

## 재현

저장소 루트에서 다음 명령으로 입력 검증·계산·비교·한국어 Markdown 보고서를 실행한다. 인터넷·API 키·LLM API가 필요하지 않다.

```bash
python -m investment_research research examples/cross_asset_case
```

같은 입력과 방법 버전은 같은 보고서와 구조화 결과를 만들어야 한다. 출처·날짜·참조·단위가 잘못된 입력은 검증 오류로 구분하며, 올바른 입력의 미확인 주장·상충 자료·개인 정보 부족은 정상적인 연구 결과로 남긴다.

[생성된 보고서](research_brief.md)와 [실행 기록](run_manifest.json)을 함께 보관한다. 파일 출력은 다음과 같이 재현한다.

```bash
python -m investment_research research examples/cross_asset_case --output reports/brief.md --manifest reports/run.json
```

실행 기록은 입력·코드·보고서 해시와 방법 버전으로 대조한다. 입력 JSON의 키 순서는 정규화하며 런타임 시각을 결과에 넣지 않는다. 기존 출력에 다른 내용이 있으면 새 경로를 사용한다.
