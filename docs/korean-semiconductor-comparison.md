## 계약과 최소 범위

`catalog/semiconductor.json`은 두 회사의 검토된 자료 경로만 등록한다. DART는 검토한 2026년 반기 접수일의 제한된 목록에서 기업 고유번호·보고기간으로 식별한다. 모든 최신 정정 공시를 자동 검색하는 기능은 없다. 공시목록의 다른 기업, 중복 접수, 정정 표시가 있으면 검증을 보류한다. 본문을 열 수 있어도 원공시 재무 표 계약이 없으면 숫자를 임의로 추출하지 않는다.

삼성전자 IR 디렉터리에서는 실제 링크 중 최신 연결 제표를 발견한다. 파일명의 연도·분기와 본문의 기업·연결·KRW/USD 열·기간을 함께 검증한다. 현재 검토된 손익 형식은 연간과 반기다. 더 최신의 미검토 형식이 생기면 오래된 파일로 돌아가지 않고 gap을 남긴다. 전체 보고서·일반 PDF 다운로드로 범위를 확대하지 않는다.

삼성전자의 단독 질문은 삼성전자 자료만 요청한다. 두 회사 비교도 전체 Opportunity Scan이나 미국 거시 수집을 추가하지 않는다. 기존 32회 요청·12 provider 한도를 유지하고 기업 재무 입력과 가격을 community보다 먼저 확인한다. 원문 댓글은 새 provider당 최대 두 후보를 열고 다른 회사의 핵심 입력을 소진하지 않는다. 질문 조합이 한도를 넘으면 미조사 provider를 기록한다.

## 같은 공식과 같은 회계 기준을 구분

모든 산술은 Decimal precision 50이며 결과의 input ID는 실제 evidence를 가리킨다. 한 분기 이익을 네 배로 연간화하거나 결측을 0·직전 분기로 채우지 않는다.

| 계산 | 정의·조건 |
| --- | --- |
| TTM 실적 | 삼성전자: 전년 연간 + 현재 반기 − 전년 반기. SK하이닉스: 마지막 연속 네 분기. 기업·단위·범위·조정 정의가 다르거나 분기가 빠지면 중단 |
| TTM EPS | 삼성전자는 공식 기본 보통주 주석을 확인한 연간/반기 EPS 합산. SK하이닉스는 제공자가 명시한 가중평균 보통주 EPS의 연속 네 분기 합산이며 잠정 |
| trailing 배수 | 표시 종가 / TTM EPS. 분모가 0·음수이거나 가격·정의가 미확인이면 만들지 않음 |
| 이익수익률 | TTM EPS / 표시 종가 × 100. 배당·확정 수익률·미래 기대수익이 아님 |
| 매출/영업이익 변화·마진 | 같은 회사·회계 범위·단위의 전년 동분기와 비교. 전년 이익이 0·음수면 일반 성장률 보류 |
| 영업외 손익 단서 | 같은 제공자 손익표의 세전이익 − 영업이익과 그 세전이익 비중. 원공시 없이 환차익·파생·일회성으로 이름 붙이지 않음 |
| 현금 창출 보조값 | 삼성전자 반기 CFO − 유형자산 취득 현금지출. 인수·리스·무형자산 등을 포함한 전체 FCF나 경영진 CAPEX와 다름 |

기간별 EPS는 가중평균 주식 수의 변화 때문에 현재 주식 수로 재작성한 EPS와 차이가 날 수 있다. 같은 산술 공식만으로 두 기업의 연결·지배주주 귀속·희석 기준이 완전히 같다고 인증하지 않는다. SK하이닉스 원공시 대조 전에는 잠정 배수의 순서를 투자 우위로 승격하지 않는다.

Euroland BVPS는 **총자본에서 무형자산을 차감**한 주당 값이다. 이것을 일반 P/B로 비교하지 않는다. 현재 주식 수·우선주와 보통주·자본 귀속도 검증되지 않아 시가총액·일반 P/B·시총/영업이익을 보류한다. Forward consensus의 기간·작성일·analyst/company 구분·revision이 없으면 forward P/E를 만들지 않는다.

## 출처 대조와 시점

삼성전자 상세 제표의 매출·영업이익은 같은 분기 공식 발표문의 소수점 한 자리 조 원 숫자와 대조한다. 차이가 0.05조 원을 넘으면 반올림 일치로 처리하지 않고 mismatch를 공개한다. SK하이닉스의 같은 Euroland 응답을 여러 필드로 읽은 것은 독립적인 원공시 검증이 아니다. 동일 URL의 SourceSpec들은 `origin_source_id`로 의존 관계를 남긴다.

현재 가격은 실제 표시 날짜 기준 7일, 분기 제표는 최신 보고기간 기준 135일, 연간 합산 입력은 400일, community는 21일 창을 사용한다. 이전 분기 비교 값은 최신 문서에 실린 역사적 입력이며 현재 분기 숫자로 바꾸지 않는다. 창 안에 있다는 사실이 최신 정정판 확인을 대신하지 않는다.

`published_at`, `observed_at`, `retrieved_at`, `valid_as_of`, raw/normalized hash와 source version을 기존 모델에 남긴다. 공식 PDF의 최초 공개시각은 unknown이므로 획득 시각을 이용 가능 시점의 하한으로 쓰고 과거에 소급하지 않는다. 기존 parser가 인식한 지정 날짜 질문은 현재 자료를 획득해 당시 자료로 사용하지 않는다. 과거의 저장된 실행은 원래 cutoff와 snapshot만 재생한다.

## 보고서와 기록

`company_comparison.json`은 가격·공시등록 evidence ID, 계산 ID, 공식 발표문 대조·불일치, 검증하지 못한 정의와 우열 판단 제한을 기록한다. run manifest에 포함되고 checksum을 검사한다. 한국어 본문에는 사업과 가격, 독립적인 양사의 Bull/Bear, 이익의 질, 회사 주장/실적/추론/community의 구분을 설명한다. 상세 자료·계산·claim·발견 로그는 같은 보고서의 접힌 근거 기록으로 연결한다.

두 기업은 KRW 상장자산이다. 미국 주식의 USD/KRW 투자 통화를 그대로 적용하지 않는다. 기업의 해외 사업 환율 영향과 투자자의 상장 통화는 구분한다. 사용자 보유·부채·필요 자금이 없으면 개인 매수 적절성이나 배분을 확정하지 않는다.

## 실행 환경과 검증

```bash
python -m investment_research ask '삼성전자랑 SK하이닉스 지금 둘 중 뭐가 더 나아?'
python -m investment_research ask --replay reports/semiconductor_comparison_validation_20261005T121543Z/live_comparison
python -m unittest discover -v
```

Python 패키지 의존성은 추가하지 않았다. **공식 PDF의 live 획득만 선택적 로컬 `pdftotext` 실행 파일**을 사용한다. 이 클라우드에 이미 설치된 실행 파일을 확인했다. 없으면 PDF evidence를 미확보로 표시하며 다른 자료로 채우지 않는다. Linux decoder는 shell/네트워크 없이 입력 2 MiB, 출력 4 MiB, CPU/메모리/시간을 제한한다. 원본 PDF 전체를 snapshot에 저장하지 않는다. 기존 source 경로와 저장된 replay는 decoder가 없어도 동작한다.

기존 325개와 새 27개, 총 **352개 테스트**가 offline으로 통과한다. 새 fixture의 수치·문구·PDF 레이아웃은 모두 작성한 합성 입력이다. 손익·EPS·현금흐름의 수동 기대값, 회계/통화/분기 혼합, 누락·정정·가격 시점·주식 종류, 외부 원문과 좁은 community claim, 이전 구현 호출, 입력까지의 추적과 동일 replay를 검증한다. 실제 자료 획득·접근 실패와 합성 테스트를 구분한다.
