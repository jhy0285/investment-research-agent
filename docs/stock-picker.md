# 규칙 기반 종목 추천 (Stock Picks)

2026-10-31 사용자 요청("invest가 너무 추상적이다, 종목추천기로 고도화")으로 추가했다. 기존 Broad Scan/`invest`는 사전 등록 전략이 없으면 항상 "신규 매수하지 않음, 현금 유지"로 끝났다. 이 기능은 **실제 공개 시세로 매달 종목 단위 후보를 고른다.** 같은 규칙을 과거·독립·최근 기간에 검증하고, 그 결과로 등급과 1주 단위 예시 매수 수량을 정한다. 추천은 일지에 남기고 다음 실행에서 실제 결과로 채점한다.

추천을 만드는 권한은 **고정된 결정적 규칙**에 있다. LLM·커뮤니티·자료 수는 선정이나 등급에 쓰지 않는다. 규칙이 검증을 통과하지 못하면 종목 목록은 보여 주지만 매수 금액은 0원이다.

## 실행

```bash
python -m investment_research picks run                                  # 한국+미국, 예산 1,000만원
python -m investment_research picks run --market KR --budget 5000000 --watch 삼성전자,SK하이닉스
python -m investment_research picks run --journal reports/investment_journal   # 추천 보존·이전 추천 채점
python -m investment_research picks replay reports/picks/<실행 디렉터리>        # 인터넷 없이 같은 바이트로 재현
python -m investment_research ask '삼성전자랑 하이닉스 포함해서 500만원으로 한국 주식 종목 추천해줘'
```

`ask`는 "종목/주식 … 추천·골라·뽑아", "살 만한 종목" 같은 질문을 이 기능으로 보낸다. 질문에서 시장(한국/미국), 예산(`500만원`, `1억`), 후보군에 있는 종목 이름(관심 종목 점검)을 읽는다. 비중·배분·포트폴리오 질문과 `--mode`를 지정한 질문은 기존 경로를 유지한다.

## 자료

| 자료 | 주소 | 쓰임 |
| --- | --- | --- |
| 월봉(첫 시가·마지막 종가, 분할 조정 가격) | `api.stock.naver.com/chart/{domestic,foreign}/item/<코드>/month` | 요인 계산·백테스트·사후 채점 |
| 지수 월봉 | `…/chart/domestic/index/KOSPI`, `…/chart/foreign/index/.INX` | 시장 비교 |
| 국내 시세·EPS·BPS·컨센서스 EPS·배당 | `polling.finance.naver.com/api/realtime?query=SERVICE_ITEM:<코드들>` | 현재가·가격 부담 참고값 |
| 미국 시세·PER·PBR·배당 | `api.stock.naver.com/stock/<RIC>/basic` | 현재가·가격 부담 참고값 |
| 원/달러 매매기준율 | `api.stock.naver.com/marketindex/exchange/FX_USDKRW/prices` | 미국 주식 수량 환산 |

모든 요청은 기존 `sources.read_public`을 거친다. HTTPS·공개 주소·robots.txt 확인·리다이렉트 거부·2 MiB 한도가 그대로 적용된다. robots 응답은 실행 안에서 호스트별로 한 번만 받는다. 한 실행의 요청은 최대 300개다(현재 약 216개). 원응답은 실행 디렉터리 `raw/`에 바이트 그대로 보존하고 SHA-256을 기록한다. `reports/`는 git에서 제외되므로 재배포하지 않는다. Yahoo·네이버 PC/모바일 페이지·`api.finance.naver.com`은 robots가 막아 사용하지 않는다.

가격은 분할만 조정한 **가격 수익률**이다. 배당 재투자 총수익이 아니다. 제공자 표시값이며 KRX·SEC 원장 대조는 하지 않았다. 응답이 깨졌거나 비어 있으면 해당 종목을 공백으로 기록하고 0이나 다른 값으로 채우지 않는다. 개별 월봉의 문제는 그 달만 격리한다. 종가가 0 이하면 그 달을 빼고, 시가가 0 이하면 종가는 신호에 쓰되 그 달을 매수·매도 가격으로 쓰지 않는다. 같은 달에 서로 다른 월봉이 두 개면 그 달을 뺀다.

## 후보군과 생존 편향

`catalog/stock_universe.json`에 코스피 대형주 72개, 미국 대형주 69개와 검토용 섹터 태그를 둔다. 2010~2026년 대형주 중 성공한 종목과 크게 부진한 종목(한국전력·LG디스플레이·롯데케미칼·엔씨소프트·인텔·보잉·월그린스 등)을 함께 넣었다. 다만 **목록 자체는 2026년의 지식으로 만들었다.** 그 사이 상장폐지·비상장 전환된 종목은 자료가 없어 검증에서 빠진다. 예: 월그린스(WBA)는 응답이 비어 공백으로 표시된다. 그래서 과거 성과는 실제보다 좋게 보일 수 있다. 이 편향은 다음처럼 다룬다.

- 규칙의 실력은 **같은 후보군을 매달 균등하게 산 동일가중**과 비교해 판정한다. 지수 대비 초과는 참고로만 쓴다(후보군 편향이 지수 대비 성과를 부풀리기 때문).
- 최고 등급 A는 주지 않는다. 과거 시점별 종목 구성(PIT universe)을 확보해야 A를 검토할 수 있다.

## 규칙 `stock_picker_momentum_lowvol_v1` (고정, trial_count = 1)

| 항목 | 정의 |
| --- | --- |
| 상승 강도 (모멘텀) | `종가[t−1] / 종가[t−12] − 1` (직전 1개월 제외 12개월) |
| 흔들림 (변동성) | 최근 12개 월간 종가 수익률의 표본 표준편차 |
| 점수 | `2/3 × 모멘텀 백분위 + 1/3 × 낮은 변동성 백분위`, 동점은 평균 순위 |
| 추세 조건 | 이번 달 종가 > 최근 10개월 종가 평균 |
| 분산 한도 | 섹터당 최대 2종목 |
| 선정 | 점수 순으로 추세·섹터 조건을 통과한 상위 5종목. 부족하면 빈 자리는 현금 |
| 최소 후보 | 13개월 연속 이력이 있는 종목 10개 이상일 때만 신호 |

모멘텀·저변동성은 공개 연구에서 알려진 요인이다. 이 데이터에서 조합을 탐색해 고르지는 않았지만, 알려진 요인을 고른 것은 사전 지식으로 공개한다. 가중치·기간·종목 수를 결과에 맞춰 바꾸려면 **새 버전**으로 만들고 `trial_count`를 늘린다. 이전 결과도 함께 공개한다.

PER·PBR·배당·컨센서스 EPS는 시점별 과거 판본이 없어 백테스트할 수 없다. 그래서 **선정에 쓰지 않고** 가격 부담 참고값으로만 보고서에 표시한다. 컨센서스 배수는 작성일·기간이 공개되지 않은 제공자 값이라고 표시한다.

## 시점 계약

- 신호는 *완료된* 월말 종가만 쓴다. 해당 시장의 마지막 평일 장 마감 1시간 뒤부터 그 달을 완료로 본다. 진행 중인 달의 종가는 쓰지 않는다.
- 매수는 다음 달 첫 거래일 **시가**, 매도는 그다음 달 첫 거래일 시가다. 신호 종가로 체결하지 않는다.
- 미래 월봉을 바꿔도 과거 신호가 바뀌지 않는다는 성질을 테스트한다.
- 보유 구간에 선택 종목의 월봉이 없으면 그 달을 `incomplete`로 제외하고 개수를 공개한다. 0% 수익으로 채우지 않는다.

## 검증과 등급 (`stock_pick_grade_v1`)

| 구간 | 보유 시작월 기준 |
| --- | --- |
| 과거 | ~2018-12 |
| 독립 검증 | 2019-01 ~ 2022-12 |
| 최근 | 2023-01 ~ |

각 구간에서 다음을 계산한다.
- 월평균·누적·연환산 수익과 연환산 변동성, 월말 기준 최대 낙폭
- 동일가중·지수 누적, 동일가중·지수 대비 월평균 초과와 승률
- 평균 교체 비중과 현금 비중
- 월별 초과수익을 2,000번 재추출한 95% 구간 (seed 0, 달 간 자기상관은 무시)

거래비용은 편도 0.25%다. 교체된 비중에만 부과하며 세율 상수가 아닌 실행 가정이다. 비용 2배 결과도 함께 계산한다. 빈 자리의 현금 이자는 0%로 둔다.

| 등급 | 조건 | 금액 (한 종목 상한) |
| --- | --- | --- |
| B 검증 통과 | 세 구간 모두 동일가중 대비 월평균 초과 > 0, 과거+검증 95% 구간 하단 > 0, 표본 24/24/12개월 이상 | 예산의 20% |
| C 조건부(소액) | 과거+검증 평균 초과 > 0, 최근 > 0 | 예산의 5% |
| D 추천 중단 | 그 외, 또는 표본 부족 | 0원 (관심 목록만 표시) |

비용을 두 배로 했을 때 과거+검증 초과가 0 이하가 되면 한 단계 내린다. 일지에 기록된 실제 추천이 6개월 이상 쌓였는데 동일가중보다 나쁘면 한 단계 내리고 `경고`로 표시한다. 예산은 요청한 시장 수로 똑같이 나눈다. 시장 안에서는 5칸으로 나누고 등급 상한을 적용한 뒤 1주 단위로 수량을 정한다. 남는 금액은 현금이다. 이 예시는 예산이 1년 이상 쓰지 않을 여유자금이라는 가정이며, 개인 재무 상황은 반영하지 않는다.

## 일지와 사후 채점

`--journal`을 지정하면 `stock_picks/<시장>/<신호월>_<해시>.json`에 추천을 불변으로 남긴다. 같은 신호월·같은 종목·같은 모델이면 다시 쓰지 않는다. 다음 실행은 새로 받은 월봉으로 이전 추천을 채점한다. 보유 구간(다음 달 시가 → 그다음 달 시가)이 끝난 기록만 채점하고, 끝나지 않은 기록은 `미성숙`으로 남긴다. replay는 실행 당시 읽은 일지(`journal_inputs.json`)만 사용한다.

## 실행 디렉터리

`raw/*.body`, `acquisition.json`(URL·robots·상태·해시), `journal_inputs.json`, `picks.json`(추천·등급·배분·밸류에이션), `backtest.json`(월별 결과·이번 달 전체 순위), `report.md`, `picks_manifest.json`(버전·코드 해시·출력 해시)을 남긴다. `picks replay`는 원응답 해시를 확인하고 다시 계산해 보고서 바이트가 같은지 검사한다. 코드가 바뀌어 결과가 다르면 종료 코드 1과 이유를 출력한다.

| 시장 | 과거 | 독립 검증 | 최근 | 등급 |
| --- | --- | --- | --- | --- |

- 미국은 비용 전에도 동일가중보다 나빴다(과거 −0.12%p, 검증 −0.47%p, 최근 −0.24%p).
- 두 시장 모두 **D(추천 중단)**다. 보고서는 이번 달 규칙 상위 종목(한국: KT&G·S-Oil·삼성화재·메리츠금융지주·삼성전기, 미국: 존슨앤드존슨·코카콜라·머크·애플·엑슨모빌)과 관심 종목 순위를 보여 주지만 예시 매수 금액은 0원이다.
