# 구현 로드맵과 최소 리서치 시스템

2026-10-07 [투자 판단·사후검증 순환](investment-cycle.md)을 구현했다. 아래 이전 단계 표의 추천·가설 실험 보류 항목은 과거 MVP 경계를 기록한다. 현재는 등록된 시점 보장 자료의 과거/최근 검증, 실제 현재 신호, A/B/C/D/F와 행동, 제약 기반 신규 자금 배분, 일지·추천 성과·전략 경고 피드백·버전 변경을 실행한다. 다음 주요 데이터 작업은 실제 장기 상품 총수익·환율·당시 이익 전망/거시 판본의 검토된 어댑터다. 현재 원자료와 장기 검증이 없으면 승인을 만들지 않는다.

## 1. 구현 순서

순서는 **사용자·현재 시장의 질문에서 대안 비교와 이해 가능한 근거까지 연결되는 작은 연구**를 기준으로 정한다. 기존 ETF 총수익·낙폭 경로는 유용한 정량 도구지만 첫 제품의 정의에서 분리한다. 조사 결과가 적거나 결론이 유보되어도 근거와 한계가 충실하면 정상적인 결과다. 합성 연구·공개 출처·거시 경로, 실제 15영역 Opportunity Map과 첫 미국 주식 Deep Dive를 완료했다. 추가 도구·자산 확장은 다음 연구 질문에 필요할 때만 진행한다.

표의 단계는 개발 이력과 확장 계획이며 사용자가 거쳐야 하는 연구 순서가 아니다. [독립 진입점](research-modes.md)의 직접 Deep Dive·Compare·Portfolio Review는 Scan 없이 시작한다. 정량 도구와 자산·계좌 확장은 실제 질문에 필요한 순서로 진행한다. Compare/Portfolio Review MVP의 확장도 실제 대안·보유 입력과 고유 방법부터 추가한다. 선택 확장은 관련 근거·검증 조건을 충족해야 하며 미완성 입력 검증을 대신하지 않는다. 상세 세금 계산이나 전체 자산 지원이 기본 비교 브리프의 선행 조건은 아니다. 지원하지 않는 항목은 명시적으로 제한한다.

기회 탐색과 조사 우선순위는 초기부터 연구의 목적이다. 다만 자동 미래 수익 예측은 별도의 결과 유형과 검증을 필요로 한다. 예측을 도입하면 미사용 기간의 오차·안정성과 확률의 보정 상태를 검증하고 비용·불확실성·실패 경로를 공개한다. 비교 가능한 근거가 없으면 기회를 확정하거나 후보를 억지로 선택하지 않는다.

## 2. Minimum Viable Research System

### 답할 질문

> 명시한 현재 기준 시점과 사용자 상황에서, KRW 현금성 자금 유지·지정한 국채 노출·주식 노출 중 무엇을 더 조사할 이유가 있으며, 어떤 기회비용·위험·정보 부족 때문에 지금 결론을 유보해야 하는가?

이는 첫 합성 검증 사례의 범위이지 영구 투자 universe나 모든 모드의 의무 입력이 아니다. 여러 자산군과 현금 대안은 이 사례에서 cross-asset 경계를 검증하기 위해 함께 다룬다. 직접 BTC·부동산·배당 전략 질문에는 그 대상을 잘 설명할 수 있는 최소 연구를 사용한다. 주택 구입 계획 등이 중요하면 부동산·부채 상환의 관련성을 검토한다. 특정 ETF·수익률 계산·전 시장 Scan을 제품의 완료 조건으로 강제하지 않는다.

현재 최소 시스템은 네 진입점의 자연어 질문을 실제 수집·기존 검증·가능한 계산·반대 설명·UNKNOWN·한국어 보고서로 연결한다. BTC에는 need 기반 공개 목록/발행자/검색 발견을 추가해 사전 등록하지 않은 최종 URL·관측·판본을 검증한다. 다른 자산은 기존 검토된 catalog와 고유 방법 중심이고 arbitrary web search나 전체 자산의 완전한 금융 실행은 아니다. BTC 직접 질문과 광범위한 기회 탐색, S&P500/Treasury 비교를 실제 자료로 실행했고 보유 구성은 합성 자기보고 입력으로 검증했다. 다음 확장은 현재 질문의 가장 중요한 데이터 공백을 줄이는 것으로 정의한다.

### 입력과 제약

- ResearchBrief의 기준 시점·질문·기간·KRW, 자기보고·unknown을 구분한 작은 ProfileSnapshot.
- 현금성·국채·주식 대안, 선택·제외 이유, ComparisonFrame의 수익 정의·유동성·비용/세금 상태·손실 경로.
- 관련 거시와 사업·상품 근거의 원문 구절·출처·시점, 숫자가 있다면 관측·계산 참조와 단위.
- 지지와 반대 자료, 동일 원출처를 공유하는 중복, 검증되지 않은 커뮤니티 주장, 검토 결과와 조건부 해석.
- 개발 검증은 합성 자료 묶음으로 한다. 합성 문서·기관·숫자는 fixture로 표시하며 실제 공식 출처나 현재 시장 근거처럼 제시하지 않는다.
- 실제 연구는 적법하게 확보한 자료를 원문·기준 시점·검토 상태와 함께 사용할 때만 가능하다. 기존 `research` parser는 `synthetic: true`와 합성 식별자만 허용한다. `sources acquire/replay`·`macro acquire/replay`가 실제 자료·거시를 같은 근거·주장 모델로 연결한다. `opportunity replay`·`deep-dive replay`는 고정 초안·원문 숫자·계산·선택적 이전 맥락을 재현한다. 기본 `ask`는 검토된 source catalog를 최소 scope로 투영해 같은 acquisition/validation을 실행한다. `--plan-only`는 계획만 출력한다. 임의 source URL·금융 숫자·투자 순위·개인 배분은 생성하지 않는다.

자료 묶음의 출처 ID와 형식이 맞는다는 사실이 내용·해석의 타당성을 보증하지 않는다. 첫 버전은 명시적으로 검토된 주장과 원문을 입력으로 받아 검토 기록을 공개한다. 새로운 시장 사실·미래 수익·내재가치·상대 매력을 자체 생성하지 않는다. 개인 입력이 부족하면 조건부 일반 비교까지만 허용한다.

### 최소 출력

1. 현재 중요한 시장 질문과 관련 자료, 조사한 대안·보류 대상·범위를 보여 준다.
2. 비교 축별로 근거·기회비용·손실 경로·비교 가능 여부를 보여 준다. 주식 과거 수익률과 국채 수익률을 같은 미래 수익률로 순위화하지 않는다.
3. 거시·사업·정량·커뮤니티 관점을 구분하고, 반대·상충·미확인 주장과 검증할 질문을 연결한다.
4. 사용자 자금수요·보유범위·집중위험·부채·주택 계획의 관련성 및 개인화 제한을 설명한다.
5. 조건부 해석·추가 관찰·재조사 조건을 제시한다. 강한 결론의 근거가 부족하면 이를 명시적으로 출력한다.
6. 출처·검토·자료·실행 버전으로 되돌아갈 수 있는 한국어 정형 비교 보고서와 실행 기록을 만든다.

판단 유보가 현금 우위의 증명은 아니다. 현금 수익률·미확인 비용·세금·부동산 편익을 임의로 0 또는 수익 숫자로 넣지 않는다. 실제 매매·대출·개인 성과·세후 계산·배분 최적화는 최소 기능의 범위에 포함하지 않는다.

### 완료 조건

- 인터넷·API 키·LLM 없이 합성 묶음 하나로 브리프→검증→대안 비교→보고서를 실행한다.
- 원문·근거 ID 단절, 기준 시점 이후 출처, 단위/통화·수익 정의 불일치, 검토 상태 없는 확정 주장을 거부한다.
- 자료 묶음에 연결된 지지·반대 근거를 숨기지 않고 원출처 중복을 표시하며, unverified 커뮤니티 주장을 사실로 렌더링하지 않는다. 입력 작성자가 누락한 반대 자료나 모든 거짓 주장을 자동 발견했다고 주장하지 않는다.
- unknown 프로필에 의존한 개인화 확정·전체 포트폴리오 안전성·임의 비중·미래 수익 주장을 허용하지 않는다.
- 같은 입력·설정·방법에서 구조화 결과와 보고서를 재현한다. 수치가 있으면 검증된 참조로만 삽입한다.
- 정당한 결론 유보, 필수 자료 부족에 따른 부분/차단, 실행 오류를 구분한다. 정상 결론 유보를 실패나 현금 매수 지시로 바꾸지 않는다.
- 합성·실제 자료 표시를 보고서 요약에 유지하고, 사용자가 대안·근거·반대 논리·제약·남은 질문을 자신의 말로 설명할 수 있도록 검토한다.

현재 합성 경로의 테스트는 [오프라인 MVP 안내](offline-mvrs.md), 실제 획득·실패·replay는 [공개 출처 안내](source-acquisition.md), 실제 현재 거시 자료의 판본·계산·보고서는 [거시 안내](macro-mvrs.md)에 정리한다. 필수 입력 오류는 보고서 생성 전 차단하고 정상적인 유보는 성공으로 완료한다. 출처가 실패하면 성공 근거를 만들지 않고 나머지 기록과 영향받은 미확인 주장을 보존한다. 일반 의미의 자동 검증·전 자산군 지원은 아직 구현하지 않았다.

## 3. 첫 단계에서 만들지 않을 것

자동매매, 매수·매도 지시, 종목 랭킹, 최적 투자비중, 미래 확률, 범용 전략 탐색, 다중 에이전트 토론, 실시간 알림, 개인 계좌 연동, 전체 자산의 방법, 출처 미확인 세금 엔진은 최소 기능에 포함하지 않는다. 사용자 질문이 정해지지 않은 지표를 무조건 추가하지 않는다.

다음 확장을 고를 때는 “새 기능이 어떤 판단 오류를 줄이고 어떤 질문에 답하는가?”를 먼저 확인한다. 단순 결과만으로 충분하면 더 복잡한 모델을 도입하지 않는다.

## 이전 반도체 비교에서 남긴 과제 기록

**권한 있는 DART 원공시로 SK하이닉스의 지배주주 TTM EPS·영업외 손익을 대조한다.**

[반도체 비교](korean-semiconductor-comparison.md)는 표시 종가와 과거 EPS를 연결했고 잠정 배수가 낮은 이유를 이익의 질과 함께 살폈다. 원공시 본문이 제한되어 SK하이닉스의 연결/지배주주 귀속과 영업외 이익의 반복 가능성, 제공자 정의의 정확성은 확인하지 못했다.

이 항목은 이전 반도체 task에서 남긴 미완료 기록이다. 원공시·정정판의 같은 기간 지배주주 이익·보통주 수·기본 EPS와 영업외 손익 주석 대조는 여전히 부족하다. 이번 Opportunity Scan 개선에서는 수행하지 않았으며 새로운 후속 기능을 제안하지 않는다.

## 자연어 Opportunity Scan의 조건부 후보

[Opportunity Scan 안내](opportunity-scan.md)에 새 넓은 질문의 15영역 최소 조사, 근거 기반 연구 후보, 쉬운 한국어 본문과 상세 부록, 저장된 후보 후속 참조를 설명한다. 기존 고정 map·과거 실행·독립 Deep Dive/Compare/Portfolio Review는 유지한다. 후보는 매수나 미래 수익률 순위가 아니며, 원자료 전사·경제적 해석·개인 적절성의 상태를 구분한다.

## 최소 coverage와 반복 관측 · 완료

자산별 minimum evidence·세 coverage 상태·투자 매력의 분리, BTC/ETH·금·실제 에너지 재고·지역 전세·국내 금융비용의 작은 원자료 연결, 보존된 이전 Scan과 동일 정의 비교를 추가했다. 새 연결·재확인·개정·실제 시장 변화·선정 방법 변경을 별도로 추적한다. 모든 자산 Deep Dive와 범용 수집을 구현하지 않았으며 커뮤니티 관심의 비교 가능한 표본이 없으면 변화 주장을 보류한다.

이후에는 [권장 실행 방식](opportunity-scan.md#실행과-결과-확인)에 따라 영업일/월별 자료 갱신 때 반복 사용하고 관측·변경 기록과 근거를 검토한다.
