# 문제 정의와 투자 원칙

## 1. 해결할 문제

개인 투자자는 가격, 사업 실적, 거시환경, 상품 구조, 시장 참여자 의견을 각각 볼 수 있지만, 이를 대안 비교와 자신의 자본배분 문제로 연결하기 어렵다. 특정 자산의 분석이 정교해도 현금·채권·주택 등 다른 선택지와 사용자의 자금수요를 놓치면 적절한 판단에 도움이 되지 않을 수 있다. 복잡한 분석이 사용자의 이해를 대신하면 도구가 있어도 판단 능력은 개선되지 않는다.

이 프로젝트는 **사용자의 실제 투자 질문 → 필요한 연구 모드·범위·방법 선택 → 근거 확인 → 경제성·위험·기회비용 검토 → 쉬운 설명 → 사용자의 판단**을 지원한다. Opportunity Scan·Asset Deep Dive·Compare·Portfolio Review는 독립 진입점이며 Scan은 다른 모드의 필수 선행 단계가 아니다. 특정 자산·전략 질문은 그 대상으로 직접 시작한다. 기대수익 대비 손실 가능성이 유리한 상황을 탐색하되, 그 유리함은 언제나 데이터·방법·가정의 적용 범위 안에서 주장한다. 상세 계약은 [연구 진입점](research-modes.md)에 있다.

기대수익은 미래 결과의 평균에 대한 추정이지 관측 사실이 아니다. 첫 버전도 사용자 관련성, 대안 비교, 거시·사업·정성 근거와 정보 부족을 다루지만, 자료 없는 미래 수익률·확률·최적 비중을 만들지는 않는다. 예측 기능은 별도의 방법 검증과 표본 외 평가를 통과한 후 추가한다.

### 잠재 투자 선택지와 조사 선택

미국·한국 주식, 글로벌 ETF, 성장주·가치주·배당주, 국채·회사채, 현금·현금성 자산, 금·기타 원자재, 천연가스 등 에너지, BTC·ETH 등 암호자산, 한국 부동산과 필요한 기타 자산을 잠재 선택지로 둔다. 성장·가치·배당은 서로 겹칠 수 있는 주식의 특성이며 ETF는 여러 노출을 담는 상품이다. 이를 모두 독립적인 자산군으로 세어 분산 효과를 과장하지 않는다.

Opportunity Scan에서는 가벼운 후보 검토와 깊은 조사를 구분한다. 직접 Deep Dive는 후보 선정 없이 지정한 질문에 답한다. 거시 변화와 실제 투자 접근성, 기존 집중위험, 현금 필요 시점, 새 가설의 중요성, 검증 가능한 자료가 질문에 필요한 조사 우선순위의 이유가 된다. 인기 게시물이나 최근 가격 상승만으로 조사·투자를 자동 결정하지 않는다. 범위와 관련 보류 이유·재검토 조건을 남기되 모든 자산의 제외 문장을 의무적으로 채우지 않는다. 좁은 표본만 검토했다면 전체 시장에서 최선이라고 말하지 않는다.

## 2. 기본 사용자와 아직 모르는 정보

사용자가 밝힌 기본 맥락은 대한민국 세법상 거주자, 1998년생, 자산 축적기, 안정적인 근로소득, 장기 투자 가능, 비교적 높은 변동성 감수 의향이다. 생활비와 장기 자금수요의 기준 통화는 KRW다. 이 정보는 사용자 맥락이며, 확인된 위험 한도나 투자 적합성 판정이 아니다.

| 구분 | 의미 | 추가로 필요한 정보 |
| --- | --- | --- |
| Risk capacity · 위험 감당 능력 | 손실이 생겨도 생활과 필수 목표를 유지할 수 있는 재무적 능력 | 비상자금, 부채, 지출, 자금 필요 시점, 자산 규모, 소득 중단 시나리오, 보유자산 |
| Risk tolerance · 위험 감수 의향 | 평가손실과 변동성을 심리적으로 견딜 의향 | 실제 손실 경험, 매도 충동, 감내 기간, 사용자가 정한 한도 |

미확인 정보는 `unknown`으로 보존한다. 출생연도나 소득 안정성에서 손실 한도, 투자 비중, 레버리지 허용량을 자동 생성하지 않는다. 개인 적절성·증액 판단에는 관련 보유자산·자금수요·부채 등을 확인하고, Portfolio Review는 실제 보유와 재무 제약부터 시작한다. 사업·시장 자체의 Deep Dive에 전체 개인 원장을 선행 요구하지 않는다. 정보 부족이 제한하는 결론을 결과에 남기며 시장 매력·기존 과다 노출·추가 보유 효과를 구분한다.

## 3. 요구사항에서 보완할 부분

요구사항의 방향은 일관되지만 다음은 더 엄밀하게 정의해야 한다.

| 원래 기대 또는 표현 | 보완할 정의 | 이유 |
| --- | --- | --- |
| 기대수익 대비 downside가 비대칭적으로 유리함 | 투자 기간, 손실의 정의, 비교 대상, 추정 방법과 불확실성을 함께 명시 | 변동성, 영구 손실, 유동성 부족, 강제 청산은 서로 다른 위험이다. 한 점수로 합치면 위험이 가려진다. |
| 장기 투자와 안정적인 소득 | 현재 현금흐름과 위기 시 소득·시장 손실의 동시 발생을 따로 평가 | 근로소득과 자산이 같은 경기 충격에 노출될 수 있다. 장기 보유 가능성도 실제 자금수요로 확인해야 한다. |
| 과거 유사 조건에서 좋은 결과 | 그 시점에 알 수 있던 조건으로 표본을 정의하고 미래 기대와 분리 | 결과를 본 뒤 조건을 고르면 좋아 보이는 표본을 쉽게 만들 수 있다. |
| 여러 자산에 적용 가능한 분석 | 공통 추적·검증 틀을 공유하되 계산 방법은 자산·상품별로 선택 | 주식의 PER, 채권의 수익률, 천연가스 선물의 가격을 같은 의미로 비교할 수 없다. |
| 현금도 정상적 결과 | `판단 유보`와 `현금 보유의 기회비용`을 구분 | 분석 불능이 현금의 우월함을 입증하지 않는다. 현금도 인플레이션, 통화, 예금·발행기관 위험을 갖는다. |
| 세후·비용후 비교 | 확인된 규칙과 거래 가정이 충분한 경우에만 계산하고, 미확인 항목은 별도 표시 | 개인별 과세 상태나 계좌 요건을 모르면 세후 결과를 확정할 수 없다. |
| 반박 관점을 독립적으로 검토 | 별도 검토 절차와 관측·결정 규칙을 두되, 같은 LLM의 두 응답을 독립 증거로 세지 않음 | 모델과 출처가 같으면 오류도 공유할 수 있다. |
| 숫자는 코드가 계산 | 입력, 단위, 금융 정의, 검증된 계산 방법도 함께 확인 | 결정적 코드도 잘못된 조정가격이나 시점 정렬을 받으면 틀린 답을 재현한다. |
| 다른 자산보다 매력적 | 기간·통화·유동성·손실 경로·비용·추정 불확실성이 맞는 비교 틀을 먼저 정의 | 국채 수익률, 과거 주식 수익률, 임대수익률은 그대로 순위를 매길 숫자가 아니다. |
| 커뮤니티에서 확산되는 주장 | 관심·내러티브의 관측과 주장 내용의 사실 검증을 분리 | 반복·인기도·전문가 표현은 원자료 확인을 대체하지 않는다. |
| 부동산도 투자대안 | 투자 현금흐름·금융비용·유동성·실거주 편익을 별도 축으로 분석 | 호가나 낮은 관측 변동성을 상장 자산의 가격·위험과 동일시할 수 없다. |

보편적인 투자 수치 기준, 세율, 기대수익 목표, 전략은 정하지 않는다. 현재 실제 source 검증 사례는 공개된 소수의 출처와 좁은 수치 확인 방법을 명시하지만, 이를 전체 research의 기본 제공자나 투자 판단 기준으로 일반화하지 않는다. 구체화할 때 사용자 입력과 출처를 확인한다.

## 4. 제품의 핵심 원칙

1. **사용자의 실제 질문이 연구 흐름을 정한다.** 특정 자산·전략, 명시한 대안, 실제 포트폴리오, 넓은 기회 탐색 모두 독립적으로 시작한다. 명시적 모드가 우선이며 필요한 기준 시점·목표·제약·근거만 선택한다.
2. **수치는 증거로 추적한다.** 값마다 데이터 출처 또는 계산 실행, 기준 시점, 단위, 적용 범위를 연결한다.
3. **과거와 미래를 분리한다.** 과거 관측·표본 통계·모델 추정·가정한 시나리오를 다른 결과 유형으로 관리한다.
4. **반대 근거를 조사한다.** 지지 근거의 수보다 중요하고 서로 독립적인 근거, 설명 대안과 실패 경로를 확인한다.
5. **분석의 한계를 결과에 포함한다.** 부족한 데이터는 숨기거나 추정으로 채우지 않는다.
6. **이해가 가능한 설명을 제공한다.** 전문용어를 풀고, 설명 문장이 가리키는 근거를 사용자가 열어볼 수 있게 한다.
7. **재현과 변경 추적을 기본으로 한다.** 데이터가 개정되거나 방법이 바뀌면 이전 결과를 덮어쓰지 않고 새 실행으로 남긴다.
8. **상품과 레버리지를 별도 평가한다.** 기초자산이 유망해도 모든 추종 상품이 동일하게 유리한 것은 아니다.
9. **관련된 상대 비교를 명시한다.** 질문에 중요한 다른 선택지와 기회비용·집중 노출을 검토한다. 비교 조건이 다르면 그 차이부터 설명하며 매번 전체 자산군을 훑지 않는다.
10. **정보량보다 판단 관련성을 우선한다.** 거시·펀더멘털·정량·커뮤니티 각각의 역할과 신뢰 한계를 지킨다. 상충하는 정보와 의미 있는 기회가 확인되지 않았다는 결과를 숨기지 않는다.

## 5. 범위

### 설계 기준

문제 정의, 아키텍처, 데이터와 계산 계약, 리서치 품질 규칙, 한국 투자자 맥락, 설명 방식, 단계별 구현 계획을 문서화한다. 실시간 데이터, 실제 전략, 추천, 주문 실행은 포함하지 않는다.

### 현재 구현된 기능

명시적인 기준 시점과 사용자 상황을 가진 합성 오프라인 리서치 자료 묶음으로 현금성 자산·국채·주식 노출을 비교한다. 다른 자산군의 대안, 관련 거시·사업 근거, 반대 자료, 검증되지 않은 내러티브, 자금수요·집중위험의 미확인을 함께 다룬다. 출처·주장·입력 검토 상태를 추적해 한국어 비교 브리프를 만든다. 합성 자료는 기능 검증용이며 현재 시장에 대한 분석으로 제시하지 않는다. 실행 방법과 구체적인 한계는 [오프라인 MVP 안내](offline-mvrs.md)에 둔다.

여기에 **실제 공개 source 획득·검증 MVP**를 추가했다. 검토한 계획의 명시적 URL을 가져와 원문 또는 짧은 구절, 메타데이터·해시·획득 시점·권리·실패 진단을 snapshot으로 남긴다. 저장된 snapshot ID를 pins에 고정하면 인터넷 없이 재생하여 출처→근거→주장→기존 연구 보고서로 연결한다. 구절 존재의 확인, 동일 정의의 제한된 수치 비교, 명시한 사례 의미 검토를 구분한다. 접근 방법과 재현·검증 한계는 [source 획득 안내](source-acquisition.md)에 둔다.

[실제 사례](../examples/real_world_case/README.md)는 2024-09-18 FOMC 결정과 공개 댓글을 2026-10-04라는 고정 기준일로 사후 검토한다. Fed 공식 성명, QuantEcon 교육 자료, 실제 Hacker News 댓글 두 개의 **4개 출처·6개 근거·4개 주장**을 사용한다. 발표된 인하 폭 50bp는 같은 결정·정의·단위의 좁은 조건에서 자동 비교한다. 댓글의 인하 폭과 “지난 회의에 했어야 했다는 신호”를 결합한 주장은 일부만 확인된 사례 검토 기록이며, “모든 인하 시작은 침체 직전”이라는 주장은 미확인이다. 다른 맥락을 제시하는 구절을 자동 반증으로 세지 않는다.

이 사례는 현재 시장의 상대 매력이나 개인 적합성을 평가하지 않는다. KRW 외의 개인 입력을 unknown으로 유지하고 추천·투자비중을 만들지 않는다. 과거의 공식 발표를 확인할 수 있다는 사실과 현재 투자 근거로 충분히 최신이라는 판단은 별도다.

실제 거시 vertical slice는 [거시 MVP 안내](macro-mvrs.md)에 정리했다. CPI 원지수·명목 국채 금리·KRW 기준환율의 정의와 이용 가능 판본을 검증하고 결정적 계산으로 현재 상태를 설명한다. 별도 출처의 현재 정책 결정·사업 실적을 이후 Opportunity Map에 연결하되 거시 모듈이 정책금리·고용·성장 전체를 계산하거나 자산 매력을 판단한 것으로 확대해서 읽지 않는다.

이후 [실제 Opportunity Map](opportunity-map.md)으로 15개 투자 영역을 Broad Scan하고 제한된 후속 조사 질문을 정리했다. 현재 수치·구절과 거시 계산을 기존 모델에 연결하고, 기대·실현 사실·서사·개인 UNKNOWN을 구분한다. 최신 지역 부동산 가격·암호자산별 순유입·금 수요 등 부족한 범위를 공개하며, 연구 우선순위는 사람이 의미 검토 완료한 매력 판정이 아니다.

### 향후 확장

현재의 소수 공개 source 경로를 질문에 필요한 공식·기업·데이터·언론·커뮤니티 출처로 확장하고, 자산별 방법과 정량 계산, 연구 가설·백테스트, 부동산 조사, 상품·계좌·배분 시나리오 비교, 선택적 LLM 설명을 추가한다. source의 접근·이용 조건과 자료 의미를 먼저 확인한다. 검증된 기초 위에서 사용자가 선택지를 판단하도록 지원하며 자동매매와 거래 권한은 현재 로드맵의 대상이 아니다.

## 6. 성공 기준

사용자가 보고서를 읽고 자신의 말로 다음을 답할 수 있어야 한다.

- 이 질문을 조사한 이유와 현재 확인된 점은 무엇인가?
- 어떤 자료와 계산을 근거로 삼았는가?
- 어떤 결론은 아직 내릴 수 없는가?
- 가장 큰 손실 경로와 반대 근거는 무엇인가?
- 무엇이 달라지면 기존 해석을 수정해야 하는가?
- 다른 투자대안보다 살펴볼 이유와 기회비용은 무엇인가?
- 내 보유자산·부채·자금수요 때문에 달라지는 판단은 무엇인가?
- 어떤 대안을 조사하지 않았으며, 지금은 왜 결론을 유보하는가?

기술적으로는 동일 입력·동일 방법에서 구조화 결과를 재현하고, 잘못된 통화·시점·출처·조정 방식이 있는 입력을 거부하며, 정성 주장도 원문과 검토 상태로 돌아갈 수 있어야 한다. 정확성, 근거, 질문·사용자에 대한 관련성, 반대 논리, 이해 가능성, 의사결정 기여도를 검토한다. 자료 수·보고서 수·좋아 보이는 수익률로만 성공을 측정하지 않는다.

## 7. 기존 설계 재검토와 수정 이유

| 검토 질문 | 판단과 이번 변경 |
| --- | --- |
| ETF/가격 분석으로 좁아질 위험이 있는가? | 있었다. 과거 ETF 수익·낙폭과 CSV 계산 경로가 최소 제품을 정의하고 있었다. 이를 정량 도구의 검증 과제로 낮추고 연구 브리프·사용자·대안 비교를 최소 제품으로 올렸다. |
| Cross-asset에 어떤 개념이 필요한가? | 기준 시점의 ResearchBrief, ProfileSnapshot, MarketContext, 조사 후보·제외 이유가 있는 ResearchPlan, 비교 의미를 맞추는 ComparisonFrame을 추가했다. |
| 거시·사업·정량·커뮤니티 역할은? | 각각 환경·사업 가치와 위험·재현 가능한 수치·검증할 내러티브를 담당한다. 투자 질문에 필요할 때만 조합한다. |
| 이질적 근거를 어떻게 결합하는가? | 출처·원문·시점·검증 상태·원출처 의존·지지/반대 관계를 남긴다. 임의 가중 점수나 모델 투표로 결론을 만들지 않는다. |
| 자산별 방법을 어떻게 지원하는가? | 공통 질문·근거 계약과 자산별 적용 조건을 공유한다. 부동산과 주식 스타일, 상품 구조의 차이를 명시했다. |
| 커뮤니티를 어떻게 사용하는가? | 탐색·관심·위험·내러티브 변화의 단서로 사용하고, 내용은 상위 원자료로 확인한다. 확인하지 못한 주장은 미확인 상태다. |
| 사용자 적절성은 어디에서 다루는가? | 연구 시작부터 알려진 제약과 unknown을 기록하고, 시장 매력과 구분해 비교·배분 시나리오에 연결한다. |
| 로드맵 수정이 필요한가? | 필요하다. 브리프·출처·주장·비교 보고서가 먼저이며, 가격 계산·백테스트는 필요한 질문에 맞춰 추가한다. |
| 더 적합한 최소 시스템은? | 현금성·국채·주식의 작은 오프라인 비교 연구다. 결론 유보·반대 근거·개인화 제한도 정상 출력으로 검증한다. |
